# FunNotes · 渐进式知识管理笔记

一个**纯前端、本地优先**的笔记工具，支持笔记本、笔记树、富文本编辑、Markdown 导入、回收站与 AI 辅助。数据完全存储在浏览器本地，无需后端服务器。

---

## ✨ 功能特性

### 📒 笔记本与笔记树
- **多笔记本**：创建、重命名、删除笔记本（至少保留一个）
- **笔记树**：笔记可形成父子层级，最多 5 层
- **拖拽排序**：拖动笔记可调整父子关系或同级顺序，拖拽时有视觉提示
- **面包屑导航**：显示当前笔记的完整路径
- **右键菜单**：右键某条笔记可「新建子笔记 / 重命名 / 删除（移入回收站）」；
  右键列表空白处可「新建笔记 / 新建笔记本」等（菜单已预留，后续需求可继续补充）

### ✍️ 富文本编辑
- **标题 + 正文 + 标签**：结构化编辑
- **右键格式工具栏**：在正文区右键唤出，支持：
  - 加粗、斜体、下划线、删除线
  - 一级/二级/三级标题、**正文**（一键取消标题，变回普通段落）
  - 无序列表、有序列表、引用、代码块
  - 插入链接、插入表格
  - 清除格式（同时取消标题与加粗等）
- **即时的操作提示**：鼠标悬停（或用 Tab 聚焦）任意工具按钮，都会弹出小提示说明它的用途
- **格式状态高亮**：工具栏会高亮当前光标所在的格式（H1 / 正文 / 加粗 / 列表…），
  一眼就能看出“现在是什么格式、能点哪里取消”
- **自动保存**：编辑防抖 600ms 自动保存至本地
- **手动保存**：`Ctrl+S` 立即保存

### 📥 Markdown 导入
- 支持 `.md` / `.markdown` 文件
- 按标题层级自动生成笔记树：
  - 一级标题 → 父笔记
  - 二级标题 → 子笔记，以此类推
- **无一级标题时**：以**文件名**为标题创建一个父笔记，其余标题挂在它下面，
  避免产生大量零散父节点（文件名不可用时用空笔记「导入的文件」兜底）
- 兼容 `# 标题`、`#标题`、Setext 标题（`===` / `---`）与文件开头的 YAML front matter
- 一级标题之前的正文会并入第一条笔记，不会丢失内容
- Markdown 内容自动转换为富文本 HTML 格式，便于后续编辑

### 🗑️ 回收站
- **软删除**：笔记删除后移入回收站，不会立即消失
- **拖拽删除**：直接将笔记拖到左下角回收站按钮上即可删除
- **回收站视图**：列表显示已删除笔记，每项提供：
  - **还原**：父节点丢失时自动作为根节点存在
  - **永久删除**：彻底移除，不可恢复
- **右键小窗口**：右键左下角回收站按钮会弹出一个小窗口（与「文件」按钮同款），
  提供「打开回收站」「清空回收站」；清空前有二次确认

### 🏷️ 标签
- **标签面板**：编辑区右上角「标签 ▾」展开，逗号分隔即可录入多个标签
- **选择已有标签**：输入框右侧的小箭头可直接从已有标签中勾选填入，最后一项是「＋ 新建标签」
- **右键改名**：右键标签（标签菜单或设置页）可重命名或删除；重命名前会提示
  「该标签正在被 N 条笔记使用」，确认后**同步更新所有使用该标签的笔记**

### ⚙️ 设置
- 左下角第一个按钮，集中管理：
  - **AI 配置**：API Base、模型、API Key（仅存本机浏览器）；配置后笔记右上角出现「AI」按钮
  - **标签管理**：列出全部标签及使用数量，可右键重命名 / 删除
  - **关于**：版本、存储方式与快捷键说明

### 📁 文件菜单
左下角“📁 文件”按钮整合了：
- 导出备份（JSON，含笔记本、笔记、回收站内容）
- 导入文件（`.json` / `.md`）
- 清空所有数据（二次确认）

### 🤖 AI 辅助（可选）
- 在「设置 → AI 配置」中填入 API Base、模型、API Key（仅存本地）
- 配置完成后，笔记右上角出现「AI ▾」按钮（未配置时不显示，界面更干净）
- **AI 总结**：对当前笔记生成 3–5 条要点，结果可插入正文或丢弃
- **AI 生成标签**：根据正文生成 3–5 个标签，自动合并到现有标签
- 调用期间按钮禁用并显示加载状态，错误时展示可读信息

### 🔍 搜索
- 按标题、正文、标签实时过滤笔记

### 💾 本地持久化
- 笔记与笔记本存储在 **IndexedDB**
- AI 配置与当前笔记本 ID 存储在 **localStorage**
- 刷新或重开页面数据不丢失
- 支持导出 JSON 备份，便于迁移或恢复

## 🧠 人机交互设计原则

| 原则 | 体现 |
|------|------|
| **渐进披露** | 默认只显示标题与正文，标签、AI 配置、格式工具栏按需展开 |
| **用户控制与自由** | AI 结果可丢弃；删除可撤销；数据可导出；回收站可还原 |
| **及时反馈** | 保存状态、Toast 提示、按钮加载状态、拖拽视觉提示 |
| **容错设计** | 删除不弹窗而是移入回收站；清空数据需二次确认；还原时自动处理父节点丢失 |
| **认知负荷最小化** | 界面简洁，搜索、标签、AI 均为可选功能 |
| **一致性与标准** | 按钮样式统一，快捷键符合惯例（Ctrl+S、Ctrl+N） |
| **美观与极简** | 留白充足，色彩克制，聚焦内容 |
| **可发现性** | 图标按钮悬停即显示用途提示；「正文」用文字代替难懂的符号 |
| **状态可见** | 格式工具栏高亮当前格式（H1 / 正文 / 加粗…）；左下角按钮显示激活状态 |

## 🛠️ 技术实现

- **前端**：原生 HTML + CSS + JavaScript（无框架）
- **存储**：IndexedDB（笔记、笔记本）、localStorage（配置）
- **Markdown 解析**：marked.js
- **富文本**：`contenteditable` + `document.execCommand`
- **部署**：可直接部署于 GitHub Pages、Vercel、Netlify 等静态托管

## 🚀 快速开始

1. **下载**：将 HTML 文件保存到本地
2. **打开**：双击文件，用现代浏览器（Chrome / Edge / Firefox / Safari）打开
3. **开始使用**：
   - 点击左上角 `＋` 新建笔记
   - 点击笔记本栏 `⋯` 管理笔记本
   - 右键笔记可「新建子笔记 / 重命名 / 删除」，右键列表空白处可新建笔记
   - 在正文区右键唤出格式工具栏
   - 点击笔记右上角 `标签 ▾` 添加标签，或用右侧小箭头选择已有标签
   - 点击左下角 `⚙️ 设置` 配置 AI、管理标签
   - 点击左下角 `📁 文件` 导入 / 导出 / 清空
   - 点击 `🗑️ 回收站` 查看已删除笔记；右键它可打开小窗口清空回收站

> 如需 AI 功能：在「设置 → AI 配置」填入 API Base、模型名和 API Key，
> 之后笔记右上角会出现「AI」按钮。

## 🔐 数据与隐私

- 所有笔记与配置**仅存储在用户浏览器本地**
- 不上传任何数据至第三方服务器
- 使用 AI 功能时，请求直接发送至用户配置的 API 端点
- 建议定期使用“导出备份”功能保存 JSON 文件

---

## ⚠️ 已知限制

- 纯前端方案，数据仅存于当前浏览器，换设备或清除浏览器数据会丢失
- 多人实时协作不支持
- AI 功能需用户自备 API Key
- 富文本编辑依赖 `document.execCommand`，在不同浏览器中表现可能略有差异
- 笔记树最大深度为 5 层
