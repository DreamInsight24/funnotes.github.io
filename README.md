# FunNotes · 渐进式知识管理笔记

一个**纯前端、本地优先**的笔记工具：工作台负责导航，笔记页负责写作，
设置与回收站是两边共用的同一份组件。数据全部存储在浏览器本地（IndexedDB），无需后端。

---

## 📁 文件结构

```
index.html          工作台（纯导航：笔记本网格 + 设置 + 文件）
note.html           笔记页（笔记树 + 编辑器 + 回收站 + 设置 + 文件）
shared/
  ├── db.js         IndexedDB 封装、内存状态、数据操作、导出/导入、Markdown 导入
  ├── utils.js      genId / sanitizeHtml / 标签 / 笔记树 / 本地存储 等纯函数
  ├── ui.js         Toast / 模态对话框 / 右键菜单 / 悬浮提示 / 下拉菜单
  ├── settings.js   设置视图 + 标签面板 + 标签改名/删除流程（两页共用）
  ├── trash.js      回收站视图 + 软删除/还原/永久删除（接受「笔记本范围」参数）
  └── style.css     变量、基础样式与全部可复用组件样式
```

> 拆分的目标不是「切文件」，而是把设置、回收站、数据层真正抽成可复用逻辑：
> 工作台与笔记页 `import` 同一份实现，一份渲染 + 一份状态，行为完全一致。

## 🧭 页面一：工作台（`index.html`）

| 项 | 说明 |
|----|------|
| 主区域 | 笔记本网格：书本图标 + 名称 + 笔记数量 + 最后编辑时间 |
| 可切换视图 | **设置**（主区域整块替换，URL 不变） |
| 页脚 | 📓 笔记本 / ⚙️ 设置 / 📁 文件 |
| 笔记本操作 | 新建 / 重命名 / 删除（卡片上的 ⋯ 或右键菜单） |
| 创建后行为 | 直接进入 `note.html?nb=xxx` |
| 删除笔记本 | 永久删除 + 级联清空回收站，确认框写明「共 N 条（其中回收站 M 条）」 |
| 回收站 | **无**（回收站属于笔记页） |

## 📝 页面二：笔记页（`note.html?nb=<notebookId>`）

| 项 | 说明 |
|----|------|
| 主区域 | 笔记树 + 编辑器 |
| 可切换视图 | **回收站 / 设置**（主区域整块替换，URL 不变） |
| 页脚 | 📓 笔记本 / ⚙️ 设置 / 🗑️ 回收站 / 📁 文件 |
| 笔记本切换 | 收进页脚下拉菜单，**不离开页面**，URL 同步更新（`replaceState`） |
| 默认选中 | 当前笔记本中 `updatedAt` 最大的未删除笔记；空笔记本 → 空状态 |
| 无效 `?nb=` | 跳回工作台 + Toast 提示 |
| 回收站范围 | **仅当前笔记本**，切换笔记本时回收站内容跟随变化 |

### 编辑器

- 标题 + 正文 + 标签；正文区右键唤出格式工具栏
- 格式：加粗 / 斜体 / 下划线 / 删除线、H1–H3、**正文（取消标题）**、
  无序 / 有序列表、引用、代码块、插入链接、插入表格、清除格式
- 工具栏会**高亮当前光标所在格式**；每个按钮都有悬浮提示（键盘 Tab 聚焦也会显示）
- 自动保存（防抖 600ms）+ `Ctrl+S` 立即保存；离开页面前会先把待保存内容写库
- 标签面板：逗号分隔录入，输入框右侧小箭头可勾选已有标签，最后一项是「＋ 新建标签」

### 笔记树

- 拖拽调整父子关系与同级顺序（最多 5 层），有拖拽视觉提示
- 右键笔记：新建子笔记 / 重命名 / 删除（移入回收站，可撤销）
- 右键列表空白处：新建笔记 / 新建笔记本

### 回收站 / 设置（共用组件）

- 回收站：还原、永久删除、清空回收站（二次确认）；右键左下角回收站按钮弹出小窗口
- 设置：AI 配置（API Base / 模型 / API Key，仅存本机）、标签管理（右键重命名/删除，
  重命名会同步所有使用该标签的笔记并提示影响条数）、关于

## 📐 数据契约

**URL 参数**

- `note.html?nb=<notebookId>`；参数无效或对应笔记本已被删除 → 跳回 `index.html` + Toast

**当前笔记本**

- URL 参数优先 → `localStorage.current_notebook`（仅作「上次访问」辅助）→ 第一个笔记本
- 笔记页切换笔记本时 URL 随之 `replaceState` 更新，笔记树与编辑器重载

**回收站隔离**

- `renderTrash` 只显示 `notebookId === currentNotebookId` 的已删除笔记
- 工作台不提供回收站入口；笔记页切换笔记本时回收站内容跟随刷新

**删除笔记本的级联**

- 该笔记本下所有笔记（**含回收站中的**）一并永久删除
- 确认框写明：笔记总数 + 回收站中的数量

**默认笔记**

- `updatedAt` 最大且未删除；空笔记本显示空状态，**不自动创建**笔记

## ⚠️ 已处理的坑

| 坑 | 处理 |
|----|------|
| 跨页保存时机 | 跳转前 `await flushSave()`，不依赖 600ms 防抖；`beforeunload` 兜底 |
| 切换笔记本时未保存 | 切换前同样 `await flushSave()` |
| 无效 `nb` | 跳回工作台，用 sessionStorage 传递一条 Toast（不用模态打断流程） |
| 删除笔记本级联 | 连同回收站中的笔记一并清除，确认框写明数量 |
| 标签改名 | 提示「正在被 N 条笔记使用」，确认后同步更新所有笔记 |
| 导入内容安全 | 导入的 `.md` / `.json` 会过滤 `<script>`、`onerror` 等 |

## 🚀 运行方式

页面使用了 ES Module（`import`），**需要通过 HTTP 访问**，直接双击文件会被浏览器的
模块跨域策略拦住（「双击即用」不再是硬约束，最终由打包层保证）：

```bash
# 在项目目录下任选一种
python -m http.server 8000
npx serve .
```

然后打开 `http://localhost:8000/index.html`。

## 🔐 数据与隐私

- 所有笔记与配置**仅存储在用户浏览器本地**（IndexedDB + localStorage）
- 不上传任何数据至第三方服务器；使用 AI 功能时请求直接发往用户配置的 API 端点
- 数据库名保持 `progressive-notes`，与旧版本数据完全兼容
- 建议定期使用「导出备份」保存 JSON 文件

---

## ⚠️ 已知限制

- 纯前端方案，数据仅存于当前浏览器，换设备或清除浏览器数据会丢失
- 模块化后需要 HTTP 环境运行（见上文）
- 多人实时协作不支持；AI 功能需自备 API Key
- 富文本编辑依赖 `document.execCommand`，不同浏览器表现略有差异
- 笔记树最大深度为 5 层
