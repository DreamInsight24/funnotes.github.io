# 渐进式知识管理笔记——需求文档

## 1. 引言

### 1.1 目的
本文档定义“渐进式知识管理笔记”（以下简称“本工具”）的功能需求、非功能需求、交互设计原则及技术约束，作为开发、测试与作业评估的依据。

### 1.2 范围
本工具是一个**纯前端、本地优先**的笔记应用，支持笔记的创建、编辑、删除、搜索、本地持久化、导入导出、Markdown 渲染，并可选接入大语言模型 API 实现智能总结与标签生成。界面采用**渐进式披露**策略，降低初始认知负荷。

### 1.3 术语定义
| 术语 | 说明 |
|------|------|
| 渐进式披露 | 默认只展示核心功能，复杂功能按需展开 |
| 本地优先 | 数据默认存储在用户浏览器中，无需服务器 |
| IndexedDB | 浏览器内置的客户端数据库，用于持久化存储 |
| LLM | 大语言模型，如 DeepSeek、OpenAI 等 |
| Markdown | 轻量级标记语言，用于格式化文本 |

---

## 2. 总体描述

### 2.1 产品愿景
为个人用户提供一个**轻量、私密、可扩展**的笔记环境。数据完全由用户掌控，同时借助 LLM 提升信息整理效率。交互设计强调“用户主导、系统辅助”，避免自动化带来的失控感。

### 2.2 目标用户
- 学生、研究人员、开发者等需要频繁记录与整理信息的人群
- 对人机交互、隐私保护有较高要求的用户
- 希望以纯前端方式完成作业或原型验证的开发者

### 2.3 运行环境
- 现代浏览器（Chrome、Edge、Firefox、Safari 最新版）
- 无需后端服务器，可部署于 GitHub Pages、Vercel 等静态托管
- 需联网才能使用 LLM API 功能

### 2.4 设计理念（人机交互）
- **渐进披露**：初始界面极简，高级功能按需展开
- **用户控制**：AI 结果先预览后插入，可丢弃；删除可撤销；数据可导出
- **及时反馈**：保存状态、操作结果、错误提示均有明确反馈
- **容错设计**：删除不弹窗确认，而是提供撤销机会；清空数据需二次确认
- **认知负荷最小化**：搜索、标签、AI 功能均不强制使用

## 3. 功能需求

### 3.1 笔记管理
| 编号 | 功能 | 描述 |
|------|------|------|
| F1 | 新建笔记 | 点击“＋”或按 Ctrl+N 创建空白笔记，自动聚焦标题 |
| F2 | 编辑笔记 | 支持修改标题、正文、标签 |
| F3 | 删除笔记 | 点击删除后笔记移出列表，顶部显示 Toast 并提供“撤销” |
| F4 | 搜索笔记 | 按标题、正文、标签实时过滤列表 |
| F5 | 笔记列表 | 按更新时间倒序展示，显示标题与摘要 |

### 3.2 本地持久化
| 编号 | 功能 | 描述 |
|------|------|------|
| F6 | 自动保存 | 编辑时防抖保存至 IndexedDB，状态栏显示“编辑中…”“已保存” |
| F7 | 手动保存 | Ctrl+S 立即保存 |
| F8 | 数据恢复 | 刷新或重新打开页面后，笔记从 IndexedDB 自动加载 |

### 3.3 导入导出
| 编号 | 功能 | 描述 |
|------|------|------|
| F9 | 导出备份 | 将所有笔记导出为 JSON 文件，包含版本、时间戳、笔记数组 |
| F10 | 导入笔记 | 选择 JSON 文件，解析并合并到本地；重复 ID 自动跳过 |
| F11 | 导入反馈 | 显示新增数量与跳过数量 |

### 3.4 渐进式界面
| 编号 | 功能 | 描述 |
|------|------|------|
| F12 | 默认简洁 | 编辑器默认只显示标题、正文、保存状态、删除按钮 |
| F13 | “更多”面板 | 点击“更多”展开标签、API 配置、AI 操作按钮 |
| F14 | 面板收起 | 再次点击收起，状态可记忆（可选） |

### 3.5 大模型 API 集成
| 编号 | 功能 | 描述 |
|------|------|------|
| F15 | API 配置 | 用户填写 API Base、模型名、API Key，仅存于 localStorage |
| F16 | AI 总结 | 对当前笔记正文生成 3-5 条要点，结果可预览、插入正文或丢弃 |
| F17 | AI 生成标签 | 根据正文生成 3-5 个标签，自动合并到现有标签中 |
| F18 | 调用反馈 | 请求期间按钮禁用并显示加载文案；错误时展示可读错误信息 |
| F19 | 结果可控 | AI 结果不直接修改笔记，需用户确认插入 |

### 3.6 Markdown 支持
| 编号 | 功能 | 描述 |
|------|------|------|
| F20 | Markdown 编辑 | 正文输入框支持 Markdown 语法 |
| F21 | 编辑/预览切换 | 提供“编辑”与“预览”模式切换按钮 |
| F22 | 实时渲染 | 预览模式使用 marked.js 将 Markdown 转为 HTML |
| F23 | 换行支持 | 开启 `breaks: true`，单回车即换行 |
| F24 | 安全过滤 | 使用 DOMPurify 清理渲染后的 HTML，防止 XSS |
| F25 | 列表摘要去标记 | 列表摘要中剥离 Markdown 符号，展示纯文本 |
| F26 | 代码高亮（可选） | 引入 highlight.js 对代码块着色 |

### 3.7 清空数据
| 编号 | 功能 | 描述 |
|------|------|------|
| F27 | 清空入口 | 侧边栏底部“清空”按钮 |
| F28 | 二次确认 | 连续两次 confirm 确认，防止误触 |
| F29 | 清空范围 | 清除 IndexedDB 中所有笔记、localStorage 中 AI 配置 |
| F30 | 状态重置 | 清空后界面恢复初始空状态，AI 配置恢复默认值 |

### 3.8 快捷键
| 编号 | 功能 | 描述 |
|------|------|------|
| F31 | Ctrl+N | 新建笔记 |
| F32 | Ctrl+S | 立即保存 |
| F33 | 标题回车 | 标题输入框按 Enter 跳转至正文 |

## 4. 非功能需求

### 4.1 性能
- 笔记列表渲染在 200 条以内无卡顿
- 保存操作防抖 600ms，避免频繁写入
- LLM 请求超时时间建议 30s，超时显示错误

### 4.2 可用性
- 界面语言为中文，文案简洁明确
- 所有按钮有悬停反馈，禁用状态有视觉区分
- 空状态有引导文案，避免用户迷茫
- Toast 提示 2.2s 自动消失，带操作按钮时延长至 6s

### 4.3 兼容性
- 支持 Chrome、Edge、Firefox、Safari 最新两个版本
- 响应式布局：窄屏下侧边栏收窄，编辑区自适应

### 4.4 安全性
- API Key 仅存储在用户本地浏览器，不发送至任何第三方服务器（除用户配置的 API 端点）
- Markdown 渲染必须经过 DOMPurify 过滤，防止 XSS
- 导入 JSON 时校验数据结构，避免恶意注入

### 4.5 可维护性
- 代码模块清晰：工具函数、DB 封装、状态管理、事件绑定分离
- 使用语义化 HTML 与 CSS 变量，便于主题扩展
- 关键操作有注释说明

## 5. 交互设计

### 5.1 布局
- **左侧边栏**：品牌、新建按钮、搜索框、笔记列表、底部操作栏（导出/导入/清空）
- **右侧主区域**：空状态或编辑器
- **编辑器顶部**：标题输入、保存状态、“更多”按钮、删除按钮
- **“更多”面板**：标签输入、API 配置、AI 操作按钮
- **AI 结果区**：标题、操作按钮（插入/丢弃）、结果内容

### 5.2 渐进披露
- 默认隐藏标签、API 配置、AI 按钮
- 点击“更多”展开，再次点击收起
- AI 结果仅在有结果时出现，不干扰正常编辑

### 5.3 反馈与撤销
- 删除笔记：Toast 显示“已删除「标题」”，提供“撤销”按钮，6 秒后消失
- 保存状态：编辑时显示“编辑中…”，保存后显示“已保存 时间”
- 清空数据：两次 confirm，成功后 Toast 提示
- AI 调用：按钮文字变为“总结中…”“生成中…”，禁用防止重复提交

## 6. 数据需求

### 6.1 笔记数据结构（IndexedDB）
```json
{
  "id": "n_xxxxx",
  "title": "笔记标题",
  "content": "Markdown 格式的正文",
  "tags": ["标签1", "标签2"],
  "createdAt": 1700000000000,
  "updatedAt": 1700000000000
}
```

### 6.2 导出文件格式（JSON）
```json
{
  "app": "progressive-notes",
  "version": 1,
  "exportedAt": "2025-01-01T00:00:00.000Z",
  "notes": [
    {
      "id": "n_xxxxx",
      "title": "笔记标题",
      "content": "Markdown 正文",
      "tags": ["标签1"],
      "createdAt": 1700000000000,
      "updatedAt": 1700000000000
    }
  ]
}
```

### 6.3 本地存储键值
| 键名 | 存储位置 | 说明 |
|------|----------|------|
| `ai_base` | localStorage | API Base URL |
| `ai_model` | localStorage | 模型名称 |
| `ai_key` | localStorage | API Key |
| `progressive-notes` | IndexedDB | 笔记数据库 |

## 7. 技术方案

### 7.1 技术栈
- **前端**：原生 HTML + CSS + JavaScript（无框架）
- **存储**：IndexedDB（笔记）、localStorage（配置）
- **Markdown**：marked.js
- **安全**：DOMPurify
- **代码高亮（可选）**：highlight.js
- **部署**：静态托管（GitHub Pages / Vercel / Netlify）

### 7.2 第三方库
| 库 | 用途 | 引入方式 |
|----|------|----------|
| marked | Markdown 转 HTML | CDN |
| DOMPurify | HTML 消毒 | CDN |
| highlight.js | 代码块高亮 | CDN（可选） |
